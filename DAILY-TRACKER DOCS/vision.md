# LifeFlow Vision

LifeFlow adalah aplikasi produktivitas pribadi yang menjadi pusat kendali aktivitas, project, kebiasaan, catatan, dan tujuan hidup.

Target Platform:
- Web
- PWA
- Mobile

Tujuan:
- Mengelola tugas
- Mengelola habit
- Menyimpan catatan
- Mengelola project
- Membuat roadmap hidup dan karir
