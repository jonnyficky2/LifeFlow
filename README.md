# Daily Tracker App 🚀

A modern productivity and habit tracker web app built with vanilla JavaScript.

## ✨ Features

- ✅ Daily task management
- 🔥 Streak system
- 📊 Productivity statistics
- 📅 Calendar task view
- 🎯 Habit tracker
- 📈 Weekly progress chart
- 🌙 Dark / Light mode
- 📦 Offline support (PWA)
- 🔔 Task reminder notification
- 📱 Mobile-friendly UI
- 💾 Local storage save system
- ↩️ Undo / Redo system
- 📤 Export / Import data

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- LocalStorage API
- Notification API
- PWA
